# ai-engineering-lab

Portfolio repository that demonstrates hands-on capability with local LLMs, agentic systems,
and structured reasoning workflows. It is organized as a professional project route, with
roadmaps, execution guides, and reproducible sessions that show how to design, implement,
and audit local AI systems end-to-end.

## Contents
- `open-llm-lab/`: core track (roadmaps + session implementations).
- `playbooks/`: supporting notes/playbooks.
- `Project_Context.md`: original scope and curation checklist.
