# open-llm-lab

Portfolio track that demonstrates end-to-end capability building local LLM systems
and agentic workflows. It combines roadmap-driven execution with practical, runnable
sessions to showcase applied engineering, not just coursework.

1) `0.Open-source_LLMs` (A -> E roadmap guided by `0_General-Roadmap.html`)
2) `1.Agentic_IA` (Sessions 1-6 with code, docs, and UI assets per session)

## How to navigate

Start here for open-source LLM fundamentals:
- `0.Open-source_LLMs/README.md`
- `0.Open-source_LLMs/0_General-Roadmap.html`

Go here for the Agentic IA sessions:
- `1.Agentic_IA/README.md`
- Session folders: `Session1` ... `Session6`

Quick index:
- `INDEX.md`

## Notes
- HTML files are interactive and store progress in your browser (localStorage).
- Session READMEs are in Spanish; this repo overview is in English.
