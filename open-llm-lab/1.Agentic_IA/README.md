# Agentic IA - Track overview

Portfolio track for building and auditing agentic systems on local infrastructure.
Each session is a runnable implementation with clear steps, constraints, and outputs.

## Contents
- `agentic_ai_curriculum.html`: visual curriculum and roadmap for the track.
- `requirements.txt`: shared dependency list used across sessions.
- `setup_env.bat`: activates the shared venv in the project root.
- `setup_session2.bat`: scaffolds Session2 (agents runtime).
- `setup_session3.bat`: scaffolds Session3 (crew runtime).
- `setup_session4.bat`: scaffolds Session4 (LangGraph research operator).

## Notes
- Session-specific READMEs live inside each `SessionX` folder.
- Framework comparison notes are in `Session5_1/docs/02_framework_comparison.md`.
