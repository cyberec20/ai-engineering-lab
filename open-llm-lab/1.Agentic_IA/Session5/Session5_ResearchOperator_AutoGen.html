Objetivo

Construir y ejecutar un sistema multi‑agente conversacional estilo “AutoGen”, con: interpretación de consultas, investigación web con fuentes, síntesis, y un flujo de HITL (Human‑in‑the‑Loop) cuando no exista evidencia suficiente. Opcionalmente, activar tracing (LangSmith / Langfuse) para auditoría.

Servidor: FastAPI
UI: /static (HTML)
Web: provider live|stub
Tracing: none|langsmith|langfuse
Puerto recomendado: 8100
Este documento es la guía paso a paso. El código ya existe en tu carpeta Session5. Aquí usamos snippets mínimos solo cuando ayudan a entender configuración / requests.

Setup del proyecto (entorno + dependencias)
