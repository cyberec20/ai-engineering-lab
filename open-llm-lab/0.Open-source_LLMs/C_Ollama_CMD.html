Ollama CLI Cheatsheet Windows

Guía rápida de comandos de Ollama para usar en CMD o PowerShell. Pensado para tu flujo de trabajo con modelos locales (Qwen, DeepSeek, Llama, etc.).

CMD · PowerShell · Windows 10/11
Comandos básicos (día a día) Uso frecuente ▶
Comando Descripción Ejemplo práctico (tú)
ollama pull <modelo>
Descarga un modelo desde el repositorio oficial de Ollama y lo deja listo para usar. Ej: ollama pull qwen2.5:7b para usarlo en tus benchmarks o scripts de Python.
ollama run <modelo>
Inicia una sesión interactiva con el modelo en la terminal (estilo chat). Ej: ollama run deepseek-r1:8b para probar razonamiento “tipo R1” sin scripts.
ollama list
Muestra todos los modelos que tienes descargados, con ID, tamaño y fecha. Útil para revisar qué tienes instalado antes de planear nuevos benchmarks.
ollama show <modelo>
Muestra información interna del modelo (licencia, parámetros, etc.). Ej: ollama show llama3.1:8b si quieres ver detalles antes de usarlo como juez.
ollama run <modelo> --prompt "texto"
Ejecuta un único prompt sin entrar en modo chat interactivo. Útil para pruebas rápidas o desde scripts por lotes (por ejemplo, comprobar que el modelo responde).
Gestión de modelos y servidor Memoria · limpieza ▶
Comando Descripción Ejemplo práctico (tú)
ollama serve
Arranca el servidor HTTP local de Ollama (API en http://localhost:11434). Solo necesario si la app no lo levanta sola y vas a probar scripts como tus benchmarks en Python.
ollama ps
Muestra qué modelos están activos/cargados en memoria actualmente. Útil para ver si un modelo quedó “pegado” consumiendo RAM/VRAM tras un test largo.
ollama stop <modelo>
Detiene un modelo que está corriendo y libera memoria asociada. Ej: ollama stop deepseek-r1:8b si lo usaste para reasoning y ya no lo necesitas.
ollama delete <modelo>
Elimina un modelo descargado y libera espacio en disco. Útil cuando decides que un modelo no te aporta tanto y quieres quedarte con menos (ej. limpiar DeepSeek si Qwen gana).
Creación y uso avanzado Más adelante ▶
Comando Descripción Ejemplo práctico (tú)
ollama create <nombre> -f Modelfile
Crea un modelo propio a partir de un archivo Modelfile (basado en otro modelo base). Más adelante, podrías crear franklin-qwen con tu system prompt personalizado y ajustes para tu estilo.
ollama run <modelo> -f archivo.txt
Usa el contenido de un archivo como prompt (útil para prompts largos o plantillas complejas). Por ejemplo, para pasar un prompt maestro de benchmarking o un caso de negocio largo sin pegarlo en consola.
ollama run <modelo> --temperature 0.2
Ajusta la temperatura del modelo (0 = más determinista, >0 = más creativo). En tus benchmarks, lo normal es usar 0.2–0.3 para respuestas más estables y menos aleatorias.
ollama run <modelo> --keepalive 0
Evita que el modelo quede cargado en memoria una vez termina la ejecución. Útil si quieres hacer pruebas puntuales sin que el modelo se quede ocupando VRAM/RAM después.

Contexto para tu uso

Este cheatsheet está pensado para:

  • Integrar Ollama con scripts Python y tus proyectos de IA local.
  • Manejar memoria y modelos sin volverte loco con cien comandos.

Tips rápidos

  • Para tus scripts de benchmark, céntrate en pull, run, list, ps y stop.
  • Si algo no responde desde Python, comprueba que el servidor esté activo con ollama serve o que la app esté abierta.
  • Cuando el disco o la VRAM se llenen, revisa ollama list y borra lo que no usas con ollama delete <modelo>.
